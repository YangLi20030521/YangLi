# In-memory data requirements

No data files or file-reading paths are provided in this public template. Required objects are registered by key using R/inputs.R; see input_objects.csv. Named object bundles replace historical workspace loading. Data provenance, preprocessing scale, cohort eligibility, endpoints and patient/sample mappings must be verified separately.

Referenced sources include TCGA-PRAD, DKFZ2018, GEO bulk and single-cell series, spatial GSE230282 as identified in the manuscript, immunotherapy-treated cohorts, DepMap, Xena, HPA, CancerSEA and drug-response resources. Public identifiers are not personal directory names. No clinical benefit or independent validation is implied by their inclusion.
